# ProxySQL + 中文 Web 管理面板

ProxySQL 数据库代理 + 自研中文管理面板（无第三方面板依赖）。

```
浏览器 ──8080──> admin-ui 中文管理面板 ──6032(仅内网)──> ProxySQL ──6033──> 你的 MySQL
                                            本地客户端(Navicat/DBeaver等) ──6033──┘
```

## 面板功能

- 概览：版本、查询量、客户端连接、连接池状态、各账号前后端连接数
- 后端数据库：增删改、状态切换、按实例选填管理账号（用于自动建号授权）
- 账号管理：独立表单页增删改；可选"同步到后端 MySQL"——选实例、多选库、
  只读/读写/全部三档权限，自动 CREATE USER + GRANT（更换库/权限自动清旧授权）
- 每个账号的「连接」按钮：弹窗显示主机/端口/用户名/密码（显隐+复制）/命令行示例
- 面板登录密码：右上角「改密」随时修改（存哈希，修改后所有旧会话失效）
- 所有 ProxySQL 配置改动自动 LOAD TO RUNTIME + SAVE TO DISK，另有"全部重载"兜底

## 使用步骤

1. 把整个 `proxysql-admin/` 目录上传到服务器并进入该目录
2. 编辑 `proxysql.cnf`：把 `mysql_servers` 里的地址改成你的后端 MySQL
   （各类密钥不用手动改，install.sh 会生成；`mysql_users` 里的代理账号按需改）
3. 运行初始化：`chmod +x install.sh && ./install.sh`
   - 首次运行自动生成 32 位随机密钥（大小写+数字）写入 `.env` 与 `proxysql.cnf`，并构建启动服务
   - 重复运行不会覆盖已有配置；`--skip-docker` 只生成配置不启动
   - 记下打印的「面板初始密码」（也存在 `.env` 文件里，权限 600）
4. 浏览器访问 `http://服务器IP:8080`（防火墙只对自己的 IP 开放），用初始密码登录
5. 立即点击右上角「改密」修改面板登录密码（修改后所有旧会话失效）
6. 在"后端数据库"页检查实例；需要自动建号授权就给实例填写管理账号
7. 本地客户端连 `服务器IP:6033`（如需对外开放，防火墙两层都要限 IP）

## 注意事项

- 自动建号授权的原理：CREATE USER/GRANT 需要一条有特权的管理连接，这是 MySQL
  权限模型决定的，不给管理账号就无法在后端建号。管理账号两种配法（可并存）：
  ① 在"后端数据库"页添加/编辑实例时填写"管理账号"（按实例存放在面板本机数据文件
  ui-data/ 中，明文保存注意目录权限）；② compose 里的 MYSQL_MGMT_* 环境变量作为默认实例。
- 未配置任何管理账号时，面板里添加的"账号"只是 ProxySQL 代理层的入口账号，
  后端 MySQL 上必须存在同名同密码的账号才能连通，需手工执行 CREATE USER。
- `--initial` 表示每次重启以 cnf 文件为准（会覆盖面板里做过的修改）。
  部署稳定后建议把 compose command 里的 `--initial` 去掉，之后统一在面板里改配置。
- 6032/6033 均未映射宿主机端口；6033 若要对外开放，在 compose 里加
  "6033:6033" 映射并配合两层防火墙限 IP。
- 面板与 ProxySQL 2.0+ / 3.x 兼容；面板与 ProxySQL 限制 `admin` 用户只能本机连管理口，
  故 cnf 里内置了第二个管理账号 `uiadmin` 供面板使用。
